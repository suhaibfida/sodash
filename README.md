#  Installation & Setup

## 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

---

## 2️⃣ Install dependencies

### Install all dependencies (root + apps)

```bash
bun install
```

Or if separate:

```bash
cd client
bun install

cd api
bun install
```
